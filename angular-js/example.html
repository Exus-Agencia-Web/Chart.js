🚀 Características del Wrapper

  • Integración completa con Chart.js 4.x
  • Directivas declarativas para todos los tipos de gráficos
  • Actualización reactiva automática de datos y opciones
  • Servicio ChartJsService para gestión avanzada
  • Soporte para plugins personalizados
  • Callbacks para eventos del ciclo de vida
  • Compatible con AngularJS 1.2+

📖 Tipos de Gráficos Disponibles

  • <chart-line> - Gráficos de línea
  • <chart-bar> - Gráficos de barras
  • <chart-pie> - Gráficos circulares
  • <chart-doughnut> - Gráficos de dona
  • <chart-radar> - Gráficos de radar
  • <chart-polar-area> - Gráficos de área polar
  • <chart-bubble> - Gráficos de burbujas
  • <chart-scatter> - Gráficos de dispersión
